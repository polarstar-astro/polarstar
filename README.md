# 天文サークル ポーラスター：トップページ

## ファイルの役割
- `index.html`：トップページの文章、各表示項目、他ページへのリンク。
- `style.css`：色・文字サイズ・余白・画面幅別の表示。
- `polarstar-logo.svg`：ヘッダー用のロゴ画像（ベクター形式）。

## ヘッダーロゴについて
- `index.html` の `<img src="polarstar-logo.svg">` がロゴを読み込みます。
- `style.css` の `.brand img` で表示幅を調整できます。
- ロゴの文字はパス化されているため、フォントに依存せず表示されます。
- 3ファイルをGitHub Pagesの同じ階層に置いてください。大文字・小文字の違いにも注意してください。
- 初回表示で以前の画像が残った場合はCtrl+F5で再読み込みしてください。
